# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please do not open a public GitHub issue for a security vulnerability.

Use GitHub's private security advisory flow for this repository, or contact the repository owner privately with:

- A description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigation

Never include Supabase service-role keys, agent tokens, user data, or other secrets in a public issue or pull request.
